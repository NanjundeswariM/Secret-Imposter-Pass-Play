# 🕵️ Secret Imposter — Pass & Play

A fun multiplayer **Imposter guessing game** built using **HTML, CSS, and JavaScript**.  
Players pass one device around, secretly reveal their roles, discuss clues, and vote to find the hidden Imposter.

Designed to work smoothly on both **mobile and desktop screens** with a responsive UI.

---

## 🎮 Game Overview

Secret Imposter is a social deduction game where:

- Players receive a secret role
- Crew members know the hidden word
- Imposters do not know the word
- Players discuss and give hints without revealing the word
- The group votes to identify the Imposter

The Crew wins by finding all Imposters.
The Imposter wins by escaping detection.

## 🎲 Gameplay Flow

### 1. Setup Phase
Players:
- Enter names
- Select category
- Choose number of Imposters
- Select discussion timer

---

### 2. Secret Role Reveal

Players take turns:

- Tap card to reveal role
- Crew sees the secret word
- Imposters see their hidden identity
- Pass phone to next player

---

### 3. Discussion Phase

Players:
- Discuss clues
- Try to identify suspicious players
- Avoid saying the secret word

Includes:
- Countdown timer
- Pause timer
- Reset timer
- Time-up alert

---

### 4. Voting Phase

Players:
- Select suspected Imposter
- Vote together
- Reveal the final result

---

### 5. Result Phase

Shows:

- Winner
- Secret word
- Player roles
- Accused players
